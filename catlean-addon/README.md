# Race Addon for CatLean

Аддон для клиента **CatLean** (Kotlin, Fabric, MC `26.2` addon-api). Добавляет три
модуля движения в категорию `movement`:

| Модуль | Команда/алиас | Что делает |
|--------|---------------|------------|
| **NoAimStrafe** | `nas` | Стоишь на месте (прыжки разрешены), пока никто не целится. Как только вражеский прицел наводится на тебя — стрейф перпендикулярно линии огня, уводя с прицела. |
| **TargetStrafe** | `ts` | Круговой стрейф вокруг ближайшего игрока с удержанием радиуса. |
| **TargetTP** | `ttp` | Рывок к ближайшему игроку пачкой пакетов позиции до `keep-distance`. Зависит от анти-чита сервера. |

Построено по официальному шаблону [`Pan4ur/CatLean-Addon`](https://github.com/Pan4ur/CatLean-Addon):
`AddonModule`, `by setting(...)`, `@Flow`-события, entrypoint `catlean:addon`.

## Сборка

CatLean closed-source, поэтому для компиляции нужен его **addon-api jar** (его
нельзя закоммитить сюда — у каждого свой).

1. Положи jar в `mod/`, например `mod/catlean-0.1.3-addon-api.jar`.
2. Проверь имя в `gradle.properties` → `catlean_jar=mod/<твой-jar>`.
3. Нужна **JDK 25** (как в шаблоне CatLean).
4. Собери:

```bash
./gradlew build
```

Готовый jar — в `build/libs/`. Положи его в папку модов CatLean.

## Важные оговорки (читай перед тестом)

Собрать/протестировать это в CI я **не мог** — нужен закрытый addon-api jar,
JDK 25 и MC 26.2, которых в сборочном окружении нет. Код написан строго по
подтверждённому API шаблона + ванильным Mojang-маппингам. Возможные точки правки:

- **Движение (xxa/zza).** Модули пишут импульсы `player.xxa` / `player.zza` в
  обработчике `PlayerUpdateEvent`. Это стандартный ванильный способ, но сработает
  он только если это событие постится **до** `travel()` игрока. Если стрейф не
  двигает — у CatLean наверняка есть отдельное событие движения/стрейфа; переключи
  `@Flow`-хендлер на него (см. `Move.kt`).
- **`ServerboundMovePlayerPacket.Pos(...)`** в TargetTP — список аргументов
  конструктора менялся между версиями MC (позже добавили `horizontalCollision`).
  Если не компилируется под 26.2 — поправь вызов в `TargetTP.kt`.
- **Тип `player`.** Модули кастуют `player as? LocalPlayer`. Если в addon-api
  локальный игрок уже типизирован иначе — убери каст.
- **Друзья/таргет-менеджер.** Цель выбирается своим кодом (ближайший игрок), а не
  через таргет CatLean — если хочешь брать таргет ауры клиента, нужен
  соответствующий метод из addon-api.

Пришли мне `catlean-0.1.3-addon-api.jar` (или ссылку) — я декомпилирую
`su.catlean.api`, сверю сигнатуры событий/движения/таргета и доведу всё точно.
